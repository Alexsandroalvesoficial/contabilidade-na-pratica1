# Contabilidade na Prática 📚

## Sobre o projeto

O Contabilidade na Prática é um projeto de segundo cérebro desenvolvido com o Google NotebookLM para apoiar o aprendizado de contabilidade brasileira.

O objetivo é criar um assistente de estudos que explique conceitos contábeis, apresente exemplos práticos e responda a perguntas com base em fontes confiáveis e citações verificáveis.

## 🎯 Objetivos

- Estudar os fundamentos da contabilidade brasileira.
- Compreender ativo, passivo e patrimônio líquido.
- Aprender lançamentos contábeis e partidas dobradas.
- Conhecer o Balanço Patrimonial e a Demonstração do Resultado do Exercício (DRE).
- Utilizar inteligência artificial para organizar e revisar conhecimentos.
- Verificar as fontes utilizadas nas respostas geradas pela IA.

## 🛠️ Ferramentas utilizadas

- Google NotebookLM — pesquisa e estudo com fontes.
- GitHub — documentação e apresentação do projeto.
- Markdown — organização da documentação.

## 📚 Fontes de pesquisa

### 1. Conselho Federal de Contabilidade (CFC)
Site: https://cfc.org.br/tecnica/normas-brasileiras-de-contabilidade/

**Por que foi escolhido:** fonte institucional para consultar as Normas Brasileiras de Contabilidade.

### 2. Comitê de Pronunciamentos Contábeis (CPC)
Site: https://www.cpc.org.br/CPC/Documentos-Emitidos/Pronunciamentos

**Por que foi escolhido:** referência técnica para estudar pronunciamentos e conceitos contábeis.

### 3. Sebrae
Site: https://sebrae.com.br/

**Por que foi escolhido:** fonte complementar para relacionar conceitos financeiros e contábeis com situações de pequenos negócios.

> Observação: a presença de uma fonte nesta lista não significa que todo o seu conteúdo foi importado. Os documentos efetivamente utilizados serão identificados durante o desenvolvimento.

## 🤖 Diretriz do especialista

O notebook foi orientado a atuar como um tutor de contabilidade brasileira para iniciantes.

As instruções priorizam explicações claras, exemplos numéricos, citações das fontes, exercícios progressivos e transparência quando as fontes são insuficientes ou divergentes.

## 🧪 Testes realizados

As perguntas abaixo serão utilizadas para avaliar o funcionamento do notebook:

1. Qual é a diferença entre regime de caixa e regime de competência?
2. O que é patrimônio líquido e como ele se relaciona com ativos e passivos?
3. Como registrar contabilmente uma compra de mercadorias a prazo?

Para cada teste, serão documentados a resposta obtida, as fontes citadas e a verificação realizada.
